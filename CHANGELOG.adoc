= Changelog
:toclevels: 2

== 0.1.7 — bindSoftNavContext lifecycle

* Runtime uses `bindSoftNavContext({ onBoot, onLoaded })` when available; falls back to `DOMContentLoaded` + `soft-nav:loaded` / `doc-nav:loaded`.

== 0.1.6 — TOC selector and script URL

* Aside TOC query matches Default UI `site.js` (`.sectionbody>` stays inside the sect token). The previous join produced `>>`, so `querySelectorAll` threw and the rail stayed on the previous page.
* Script tag after `site.js` resolves both `ui/js/site.js` and `_/js/site.js` to `_/js/soft-nav-page-toc.js`.
* Parent breadcrumb insert keeps the separator already in front of the current crumb (one `/` between Changelog and the detail title).

== 0.1.5 — hide-page meta

* Composed HTML meta `antora-supplemental:hide-page`; `:hide-from-navtree:` legacy parse only.

== 0.1.4 — hide-page directive

* Parse `:hide-page:` alongside `:hide-from-navtree:` for nav-tree-hidden pages.

== 0.1.3 — navtree parent registry

* Resolve `:navtree-parent:` from `navtree-registry.json` and `;; navtree-parent-association:` lines in `nav.adoc` when the page directive is absent.
* Meta injection runs even when `injectScript: false`.
* Document explicit long author names (`:hide-from-navtree:`); avoid ambiguous `:omit-nav:` / `:nav-hidden:` in proposals.

== 0.1.2 — breadcrumbs and hide-from-navtree

* Meta tags use `hide-from-navtree` and `navtree-parent` (legacy names still read in SoftNav).
* Inject parent breadcrumb segment in composed HTML for nav-hidden pages.

== 0.1.1 — nav-hidden meta for SoftNav

* Inject `<meta name="antora-supplemental:nav-hidden">` and optional `nav-parent` from `:page-nav-hidden:` / `:page-nav-parent:` at compose time.
* Hubs with integrated `soft-nav.js` may set `injectScript: false`; TOC rebuild lives in SoftNav.

== 0.1.0 — initial release

* Publish `soft-nav-page-toc.js` and inject after Default UI `site.js` on composed pages.
* Rebuild aside page TOC on load and on `soft-nav:loaded` / `doc-nav:loaded`.
* Registry metadata for extension-lister / build-stack footers.
