== 0.1.2 — breadcrumbs and hide-from-navtree

* Meta tags use `hide-from-navtree` and `navtree-parent` (legacy names still read in SoftNav).
* Inject parent breadcrumb segment in composed HTML for nav-hidden pages.

== 0.1.1 — nav-hidden meta for SoftNav

* Inject `<meta name="antora-supplemental:nav-hidden">` and optional `nav-parent` from `:page-nav-hidden:` / `:page-nav-parent:` at compose time.
* Hubs with integrated `soft-nav.js` may set `injectScript: false`; TOC rebuild lives in SoftNav.

== 0.1.0 — initial release

* Publish `soft-nav-page-toc.js` and inject after Default UI `site.js` on composed pages.
* Rebuild aside page TOC on load and on `soft-nav:loaded` / `doc-nav:loaded`.
* Registry metadata for extension-lister / build-stack footers.
