= soft-nav-page-toc
:description: Rebuild aside page TOC after SoftNav swaps the article.

Antora extension for hubs that use https://github.com/antora-supplemental/antora-ui-chassis/tree/main/packages/soft-nav[SoftNav] with Default UI / Valentus.

Default UI `site.js` builds `aside.toc.sidebar` once at load.
SoftNav swaps mast, left nav, and article — not the right-rail TOC — so orphan/detail targets (for example changelog-details) show stale heading lists until a full reload.

This extension publishes `_/js/soft-nav-page-toc.js` and injects it after `ui/js/site.js` on each composed page.
The script rebuilds the page TOC on load and on `soft-nav:loaded` / `doc-nav:loaded`.

== Install

[source,bash]
----
pnpm add -D github:antora-supplemental/soft-nav-page-toc#v0.1.0
----

[source,yaml]
----
antora:
  extensions:
    - require: '@antora-supplemental/soft-nav-page-toc'
----

Load https://github.com/antora-supplemental/antora-ui-chassis/tree/main/packages/soft-nav[`soft-nav.js`] in supplemental UI **before** Mermaid/lightbox consumers (Facto stack demos do this).

== Nav tree parent registry

Pages that use `:hide-page:` may also need an explicit **nav tree parent** when they are not under a `*-details/` folder or when cross-tree xrefs should share one parent.

* Per page: `:navtree-parent: changelog.adoc` (wins over registry).
* Component file: `modules/ROOT/navtree-registry.json` with `parentByPrefix` and/or `pages` maps.
* In `nav.adoc` (comments only, not rendered): `;; navtree-parent-association: changelog-details/ -> changelog.adoc`

Mark nav-tree-hidden pages with `:hide-page:` and `:navtree-parent:` (see upstream proposal).

== Config

[cols="1,2"]
|===
| Key | Default

| `skip` | `false`
| `injectScript` | `true` — append defer script after `site.js`; set `false` if hub `soft-nav.js` already rebuilds the TOC
| `navtreeRegistryPaths` | `[]` — extra JSON registry paths relative to the playbook dir
|===
